# 🤖 ربات هوشمند تحلیلگر بورس ایران (TSE Smart Bot)

یک ربات تلگرامی پیشرفته و خودکار برای پایش، تحلیل تکنیکال و استخراج سیگنال از بازار بورس و فرابورس ایران. این ربات با اتکا به معماری ۴ لایه و بدون نیاز به خاموش کردن VPN، به شکل لایو اطلاعات را از سرورهای TSETMC استخراج کرده و نتایج تحلیلی پیچیده را ارائه می‌دهد.

---

## ✨ امکانات و قابلیت‌ها

### ۱. معماری مدرن و مقاوم (Data Infrastructure)
- **بدون وابستگی به وضعیت VPN:** ربات با پچ اختصاصی IPv4 تحریم‌ها و اختلالات ProtonVPN را دور زده و داده‌ها را به شکل مستقیم از طریق دکمه‌های تلگرامی واکشی می‌کند.
- **Provider Abstraction:** اتصال همزمان به دو درگاه مجزا (`cdn.tsetmc.com` و `webgw.tse.ir`) با مکانیزم Fallback. اگر یکی قطع شود، دیگری به طور خودکار جایگزین می‌گردد.
- **پایگاه داده آفلاین (SQLite Cache):** تمامی داده‌های تاریخی و تاریخچه نمادها در سرور کش می‌شوند تا در صورت قطعی کامل TSETMC، ربات از کار نیفتد.

### ۲. اسکنرهای هوشمند بازار (`/scans`)
ربات توانایی فیلتر کردن کل بازار را در لحظه دارد:
- 📈 **اختلاف قیمت مثبت/منفی:** پیدا کردن نمادهایی با بیش از ۳٪ اختلاف قیمت پایانی و آخرین معامله.
- ⚠️ **حجم مشکوک:** شناسایی نمادهایی که حجم معاملات امروز آن‌ها بیشتر از ۴ برابر میانگین ۳۰ روزه است.
- 💰 **ورود پول حقیقی هوشمند:** ترکیب دیتای `client_type` و قیمت برای یافتن خریداران حقیقی پرقدرت.
- 🚀 **مستعد صف خرید:** شناسایی سهامی که در آستانه صف خرید فردا قرار دارند.
- 🕯️ **الگوهای کندلی:** تشخیص خودکار کندل‌های بازگشتی (چکش/Hammer و ماروبوزو/Marubozu).
- 💼 **تفکیک بازار:** اسکن اختصاصی برای حق تقدم‌ها و صندوق‌های قابل معامله (ETF).

### ۳. موتور تحلیل تکنیکال و واگرایی‌ها
- محاسبه لایو اندیکاتورهای RSI, MACD, Stochastics, Bollinger Bands, OBV.
- تشخیص روند بازار با استفاده از میانگین متحرک (EMA 50).
- **موتور اختصاصی تشخیص واگرایی (Divergence Engine):** شناسایی خودکار واگرایی‌های مثبت (Bullish Divergences) مخفی و معمولی روی تمامی اندیکاتورها با بررسی Pivot های قیمتی.

### ۴. داشبورد و چارت‌های خودکار
- تولید تصویر نمودار شمعی (Candlestick) به صورت خودکار با ترسیم اندیکاتورها در پایین چارت با استفاده از `mplfinance` و ارسال به تلگرام.
- **نقشه زنده بازار (Market Map):** رسم درختی نقشه بازار (Treemap) بورس و فرابورس (`/marketmap`).

### ۵. مدیریت واچ‌لیست اختصاصی
- قابلیت افزودن نماد به لیست علاقه‌مندی‌ها (`/add فولاد`) و حذف آن‌ها (`/remove`).
- مشاهده وضعیت لایو سبد با دستور (`/watchlist`).

---

## 🏗️ معماری سیستم

سیستم از ۴ لایه اصلی تشکیل شده است:
1. **Presentation Layer (ربات تلگرام):** هندلرهای موجود در `app/handlers/` برای ارتباط با کاربر.
2. **Services Layer:** شامل `ScannerService`، `AnalysisService` و `DataFetcherService` برای اجرای منطق تجاری.
3. **Engines Layer:** موتورهای محاسباتی سنگین شامل `candles.py`، `divergence` و `indicators`.
4. **Data Acquisition Layer:** واسط یکپارچه `DataProvider` که اطلاعات خام را گرفته، نرمال‌سازی کرده (`Normalizer`) و در دیتابیس `DatabaseManager` تزریق می‌کند.

## 🚀 راهنمای دستورات تلگرام

| دستور | کارکرد |
|-------|--------|
| `/start` | راهنمای اولیه و شروع به کار |
| `/update` | منوی اینتراکتیو برای واکشی داده‌های امروز و تاریخچه بازار (بدون نیاز به اسکریپت خارجی) |
| `/today` | دریافت گزارش سیگنال‌های قوی (Confluence) و واگرایی‌های کشف شده‌ی امروز |
| `/scans` | نمایش منوی فیلترهای هوشمند (حجم مشکوک، پول حقیقی، ...) |
| `/scan` | اجرای محاسبه‌گر سنگین برای استخراج واگرایی روی کل بازار (حدود ۵ دقیقه زمان می‌برد) |
| `/watchlist` | مدیریت و نمایش دیده‌بان شخصی شما |
| `/marketmap` | دریافت تصویر نقشه گرافیکی بازار در همان لحظه |
| `[نام نماد]` | ارسال نام هر نماد (مثل `شپنا`) برای دریافت لایو تحلیل، چارت و وضعیت اندیکاتورها |

## 🛠️ راه‌اندازی (Deployment)

ابتدا نیازمندی‌ها را نصب کنید:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

سپس توکن ربات تلگرام خود را در فایل `.env` قرار دهید:
```env
TELEGRAM_BOT_TOKEN=your_token_here
ALLOWED_USER_IDS=your_telegram_id
```

و ربات را اجرا کنید:
```bash
python3 telegram_bot.py
```
